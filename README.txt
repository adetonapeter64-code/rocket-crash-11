MANUAL CRASH TARGETS — PLAY-MONEY SIMULATION ONLY

Included:
- admin.html: adds Save Targets to the existing Test / Simulation tab.
- index.html: original player page, unchanged.
- server.js: original server, unchanged.

How to use:
1. Replace the corresponding project files with these files.
2. Open the Admin Panel and select Test.
3. Enter multipliers (one per line or comma-separated).
4. Select SAVE TARGETS, then RUN TEST.

Important:
This package does not change live server crash generation, startRound(),
crashFrom(), real-money rounds, deposits, or withdrawals. Manual targets
are saved in this browser's local storage and apply only to the Admin
Panel's local play-money simulation.
